About

I write software for a living and for fun. Most recently that means Python data and test-automation work in industry, and a steady stream of side projects, many of them small native macOS tools. Before that I did a PhD on algorithms for traffic control in softwarized networks, supervised by Prof. Stefan Schmid in the Communication Technologies group at the University of Vienna. I'm most interested in roles that combine applied research with hands-on software development.

Recent Projects

  • Python · TypeScript auto_trader

    Intraday trading platform: backtesting, paper trading, and live trading via Capital.com. FastAPI backend, React frontend with a TradingView-style chart. One strategy runs unchanged from backtest to live.

  • Swift tunnel_bahn

    Native macOS app for WireGuard split tunneling: route individual applications through the tunnel while everything else stays direct.

  • Swift iranian_calendar

    Menu bar Iranian (Jalali) calendar for macOS, built with SwiftUI. Shows today's Jalali date in the menu bar, with holidays and events from Google Calendar, ICS feeds, and the system calendar.

  • Swift comfort_brightness

    Menu bar app that nudges the built-in display's brightness based on what is actually on screen: dims blinding white pages, lifts muddy dark video, and never takes control away from you.

  • Swift net-meter

    Menu bar app showing live upload/download speeds, with optional per-app bandwidth metering.

  • Swift sleep_toggle

    Tiny menu bar toggle for macOS system sleep. It keeps a docked Mac awake with the lid closed.
